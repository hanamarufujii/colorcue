# ColorCue

あなたが決めた色をカメラに見せると、AIに音声入力ができる。キーボードには触りません。

**セットアップはこちら → https://hanamarufujii.github.io/colorcue/**

---

## なにをするもの

カメラが色の目印を見ています。

色は**自分で決められます。** 青でも緑でも、紫でも水色でも構いません。
避けるのは**肌に近い色だけ**（オレンジ・赤・ベージュ）。顔ごと拾ってしまい、動かなくなります。

| 動作 | 起きること |
|---|---|
| **1つめの色を上げる** | 聞き始める。一瞬でよく、上げっぱなしにする必要はありません |
| **2つめの色を上げる** | ポーズ。考えている間、勝手に送られません |
| **合図の言葉を言う** | いま前面にあるアプリへ文を入れて Enter（既定は「はい」「送信」。画面で増やせます） |
| **数秒黙る** | 同じく送信（ポーズ中を除く。秒数は変えられます） |

**手ぶらモード**：「手ぶらモードオン」と言うか、画面のスイッチを入れると、色なしでずっと聞きます。
部屋の音を拾い続けるので、**一人きりの静かな場所でだけ**使ってください。
オンの間は、注意書きが画面に流れ続けます。設定は保存されず、開き直すと必ずオフに戻ります。

**送り先**：Claude でも、ChatGPT でも、メールでも、Word でも、検索窓でも構いません。
既定では「いま前面にあるアプリ」に入りますが、**画面で送り先を選んでおけば、
何を触っていても必ずそのアプリを手前に出してから送ります。**

## 必要なもの

- **macOS** または **Windows**
- **Google Chrome**（音声認識に Chrome の機能を使います）
- **Python 3**（Mac は最初から入っています。Windows は別途インストール）
- **色の目印を2つ**（好きな色で構いません。ペン・付箋・リストバンドなど。肌の色に近いものだけ避ける）

## 起動

### Mac（おすすめ：一度登録すれば、あとは何もしない）

**`ColorCue を自動起動する.command`** を右クリック →「開く」。一度だけです。

これで Mac を起動するたびに ColorCue が自動で立ち上がります。落ちても復帰します。
**ターミナルは開きっぱなしにしなくて構いません。** 使うときはブラウザで
`http://localhost:8777/index.html` を開くだけです。

やめたいときは `自動起動をやめる.command`、そのときだけ止めたいときは `stop.command`。

### Mac（自動起動を使わない場合）

`start.command` を右クリック →「開く」。
起動したあと、**ターミナルのウィンドウは閉じて構いません**（切り離して動きます）。

### Windows

`start.bat` をダブルクリック。黒いウィンドウは閉じずに置いておきます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | カメラ・色の追跡・音声認識。ブラウザで動く本体 |
| `bridge.py` | localhost:8777 で待ち受け、送り先のアプリへ貼り付けと Enter を送る |
| `words.json` | 聞き取りの崩れを直す置換表。崩れる言葉を足していける |

| `ColorCue を自動起動する.command` | Mac起動時に自動で立ち上がるように登録する（一度だけ） |
| `自動起動をやめる.command` / `stop.command` | 自動起動の解除 / その場で停止 |
| `uma-logo.png` | 画面のロゴを押すと出る説明に使う U-MA のロゴ |
| `docs/` | セットアップページ（GitHub Pages） |

## 画面でできること

| | |
|---|---|
| **信号ボタン4つ** | 聞き始める／送る／ポーズ／手ぶら。色を上げるのと同じことが、押してもできます |
| **送り先** | 起動中のアプリから選ぶ。選ぶと、そこを手前に出してから送ります |
| **送信の合図** | 送る言葉を自由に決められます。読点区切りでいくつでも。空にすると無効 |
| **黙ってから送るまで** | 1〜8秒。バーが減っていくのが見えます |
| **色の登録** | 映像に映った色をクリックして覚えさせます |
| **左上のロゴ** | 押すとバージョンと、なぜ作ったかが出ます |

## 置換表（words.json）

音声認識が固有名詞を外したときに直します。2種類あります。

- `replace` … 文のどこにあっても置き換える。**日本語として存在しない崩れ方だけ**入れること
- `exact` … 発話まるごとが一致したときだけ置き換える。ふつうの言葉を巻き込まないための枠

例：「クローム」が「クロ人」と聞き取られる → `"クロ人": "クローム"`。
逆に「サンゲツ」→「3月」のように**本物の言葉に化ける場合は入れない**でください。本物の「3月」まで壊れます。

## 知っておくこと

- **音声は Google のサーバーで処理されます。** Chrome の音声認識を使っているためです。
  聞いているのは色を上げている間だけですが、その間の音声は外に出ます。
  手ぶらモードの間は、それがずっと続きます。
- **ColorCue の画面が他のウィンドウに完全に隠れると、カメラが止まります。** 隠れない場所に置いてください。
- **Mac はキー送信に許可が要ります。** アクセシビリティとオートメーションの2つ。
  許可したあとターミナルを再起動しないと効きません。
- Windows 版は実機での検証がまだです。動かない点があれば教えてください。
